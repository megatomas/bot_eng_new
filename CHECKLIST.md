## 🐛 Если что-то не работает

### Бот не запускается
```bash
# Проверь .env
type .env

# Проверь зависимости
pip list | findstr aiogram

# Проверь PostgreSQL
docker ps
```

### Ошибка "TELEGRAM_BOT_TOKEN не установлен"
- Убедись что в `.env` нет кавычек вокруг токена
- Перезапусти терминал после изменения `.env`

### Ошибка "connection refused"
- Проверь что PostgreSQL запущен
- Проверь пароль в `DATABASE_URL`

### AI не отвечает
- Проверь `GROQ_API_KEY` в `.env`
- Проверь что ключ начинается с `gsk_`
- Зайди на https://console.groq.com/ и проверь лимиты
