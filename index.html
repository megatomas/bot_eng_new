🇬🇧 English Learning Bot — Установка

Пошаговая инструкция по переносу файлов на компьютер через GitHub

Важно: Файлы, созданные в этом чате, находятся в веб-среде. Чтобы они попали на твой компьютер, нужно скопировать скрипт setup_all.py (Шаг 1) и запустить его на компьютере.

📋 Шаг 1: Скопируй скрипт установки

Скопируй весь код ниже → Открой PyCharm → Создай файл setup_all.py в корне проекта → Вставь код → Сохрани

Скрипт будет ниже — прокрути вниз 👇

🚀 Шаг 2: Запусти скрипт

Открой терминал в PyCharm (Alt + F12) и выполни:

python setup_all.py

Скрипт создаст ВСЕ необходимые файлы автоматически!

🔑 Шаг 3: Настрой .env

Открой файл .env и заполни:

# 1. Токен бота (от @BotFather)
BOT_TOKEN=твой_токен_здесь

# 2. Groq API ключ (бесплатно с https://console.groq.com/)
GROQ_API_KEY=gsk_твой_ключ_здесь

📦 Шаг 4: Установи зависимости

pip install -r requirements.txt

🗄️ Шаг 5: Запусти PostgreSQL

docker-compose up -d db

Или используй локальный PostgreSQL.

▶️ Шаг 6: Запусти бота

python -m app.main
Готово! Открой бота в Telegram → /start

🔑 Где получить бесплатные ключи

Groq API (AI-собеседник)

1. Зайди на https://console.groq.com/

2. Войди через Google

3. "API Keys" → "Create API Key"

4. Скопируй ключ (начинается с gsk_...)
