# 🤖 Telegram Bot для обучения английскому языку

Полностью автономный Telegram-бот для быстрого изучения английского языка с голосовым озвучиванием слов.

## 🚀 Возможности

- **60+ слов** в 5 тематических уроках
- **5 типов упражнений**: перевод, выбор, аудирование, набор текста, соединение пар
- **Голосовое озвучивание** всех слов и примеров (Google TTS)
- **Система прогресса** с XP, уровнями и сериями
- **Интервальное повторение** — бот сам решает, какие слова повторить
- **Грамматические уроки** с примерами
- **Полностью автономный** — бот ведёт обучение сам

## 📦 Установка

```bash
# 1. Клонируйте репозиторий
git clone <your-repo-url>
cd english-telegram-bot

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Получите токен бота у @BotFather в Telegram
# Отправьте /newbot и следуйте инструкциям

# 4. Установите переменную окружения
export TELEGRAM_BOT_TOKEN="ваш_токен_здесь"

# Или создайте файл .env
echo "TELEGRAM_BOT_TOKEN=ваш_токен_здесь" > .env
```

## ▶️ Запуск

```bash
python bot.py
```

## 🎮 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начать обучение |
| `/learn` | Начать урок |
| `/practice` | Практика слов |
| `/vocab` | Словарь изученных слов |
| `/grammar` | Грамматические правила |
| `/stats` | Статистика прогресса |
| `/reset` | Сбросить прогресс |

## 🧠 Система обучения

Бот использует адаптивную систему обучения:
1. Новые слова подаются порциями (5 за сессию)
2. Каждое слово проходит через 5 типов упражнений
3. Ошибки автоматически добавляются в очередь повторения
4. За правильные ответы начисляется XP с бонусом за серию
5. Каждые 100 XP — новый уровень
