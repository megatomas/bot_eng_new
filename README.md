# 🤖 Telegram Bot для обучения английскому языку

Полностью автономный Telegram-бот для быстрого изучения английского языка с голосовым озвучиванием.

## 🚀 Возможности

- **460+ слов** в 46 тематических уроках
- **20 грамматических правил** с примерами
- **5 типов упражнений**: перевод, выбор, аудирование, набор текста, соединение пар
- **Голосовое озвучивание** всех слов и примеров (Google TTS)
- **Система прогресса** с XP, уровнями и сериями
- **Интервальное повторение** — бот сам решает, какие слова повторить
- **Полностью автономный** — бот ведёт обучение сам

## 📦 Установка

```bash
# 1. Клонируйте репозиторий
git clone <your-repo-url>
cd english-telegram-bot

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Создайте файл .env и добавьте токен
echo "TELEGRAM_BOT_TOKEN=ваш_токен_здесь" > .env

# 4. Запустите бота
python bot.py
```

## 🧠 Система обучения

Бот использует адаптивную систему обучения:
1. Новые слова подаются порциями (5 за сессию)
2. Каждое слово проходит через 5 типов упражнений
3. Ошибки автоматически добавляются в очередь повторения
4. За правильные ответы начисляется XP с бонусом за серию
5. Каждые 100 XP — новый уровень

## 🎯 Цели обучения

После прохождения всех уровней ученик сможет:
- **A1**: Понимать базовые фразы, рассказывать о себе
- **A2**: Общаться в простых ситуациях, путешествовать
- **B1**: Обсуждать знакомые темы, выражать мнение
- **B2**: Понимать сложные тексты, общаться на работе

## 💡 Советы по использованию

1. Занимайтесь каждый день по 10-15 минут
2. Не пропускайте повторения — бот сам напомнит
3. Слушайте произношение каждого слова
4. Читайте примеры использования
5. Проходите грамматику параллельно со словами
